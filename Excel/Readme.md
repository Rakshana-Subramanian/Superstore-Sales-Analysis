# 📊 Superstore Sales Analysis — Excel

## 🗂 Project Overview
Sales analysis of Superstore retail data using Microsoft Excel
to uncover trends across regions, categories and customer segments.

## 📁 Dataset
- Source: Kaggle — Sample Superstore Dataset

## 🛠 Tools Used
- Microsoft Excel
- Pivot Tables
- Charts and Visualizations
- Excel Formulas — VLOOKUP, XLOOKUP, IF, SUMIF, COUNTIF
- Conditional Formatting
- Slicers and Filters
