# Superstore Power BI Dashboard

## Project Overview
Interactive sales dashboard built using Microsoft Power BI
analyzing Superstore retail data across regions, categories and customers.

## Dataset
- Source: Kaggle — Superstore Sales Dataset

## Tools Used
- Microsoft Power BI Desktop
- Power Query — Data Cleaning & Transformation
- DAX — Data Analysis Expressions
- Data Modeling — Star Schema Design
- Visualizations — Cards, Bar Charts, Line Charts, 
  Donut Charts, Column Charts, Maps, 
  Treemap, Scatter Plot, Waterfall Chart,
  Matrix Table, Slicers, Drill-through

  ## Dashboard Pages
- Page 1 — Executive Summary ✅
- Page 2 — Regional Analysis 🔄 In Progress
- Page 3 — Product Analysis 🔄 In Progress

**The Executive Summary page provides a high level overview 
of Superstore business performance from 2014 to 2017.**

**Key Highlights:**
- 5 KPI Cards showing Total Sales, Profit, 
  Orders, Customers and Profit Margin
- Sales by Region and Segment — Donut Charts
- Monthly Sales and Profit Trend — Line Charts
- Sales by Ship Mode and Category — Bar Charts
- Profit by Category — Column Chart
- Interactive Region Slicer to filter entire dashboard
